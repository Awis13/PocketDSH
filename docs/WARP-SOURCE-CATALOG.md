# Warp documentation source catalog

Retrieved 2026-09-08 from official text bundles linked by [llms.txt](https://docs.warp.dev/llms.txt).

This is a navigation and coverage index, not 237 individually exercised features. Terminal and agent interaction pages informed the main [audit](WARP-FEATURE-AUDIT.md); setup, cloud and factory entries are catalogued for scope awareness, not comprehensively validated. No local Warp UI was inspected. A later browser pass viewed three official UI images and two playback moments of the pane-dragging demo; see the audit addendum. Page titles below retain the official names.
